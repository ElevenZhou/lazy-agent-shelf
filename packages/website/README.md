# Website Prototype

This Vite/React app is the first marketplace shell for Universal Agents.
It now includes four navigation entries: agent browsing, usage guidance, AI tool scene analysis, and a curated top-10 model watchlist.

## Run Locally

```bash
npm install
npm run website:dev
```

## Build

```bash
npm run website:build
```

The current UI is intentionally editorial/brutalist: high-contrast paper texture, oversized type, agent cards, filters, and recommended stacks.
