# Examples

## Example Prompt

用 Douyin Ad Optimizer 分析这组投流数据：目标是表单线索，日预算 3000 元，近 3 天 CTR 1.1%，CPC 4.8 元，CVR 2.2%，CPA 218 元，目标 CPA 120 元。已有 6 条素材，其中 2 条花费超过 1000 元但无转化。

## Expected Behavior

-先判断瓶颈更可能在素材点击吸引力、落地页转化，还是人群/出价。
- 输出哪些素材暂停、哪些素材拆解复用、预算如何移动。
- 给出下一轮素材脚本、测试变量、成功标准和回滚条件。

## Example Prompt

帮我看直播间千川投流，ROI 从 1.8 掉到 1.1，素材点击率没明显掉，但成交率和停留下降。

## Expected Behavior

- 不只改出价，要联动直播间承接、人货场、讲解节奏、货盘和流量质量。
- 区分短视频引流素材问题、直播间承接问题、商品/价格问题和归因窗口问题。
- 给出直播间脚本、投放计划和素材迭代的组合动作。
