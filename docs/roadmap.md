# Lazy Agent Shelf Roadmap

## Phase 0: Source Standard

- Define `agent.yaml` and `prompt.md` conventions.
- Keep source prompts platform-neutral.
- Add lint rules for required metadata, quality checklist, scope, and safety boundaries.

## Phase 1: Seed Library

- Ship the first 24 high-quality agents across engineering, product, growth, data, operations, and meta-agent categories.
- Add Chinese-localized agents for Feishu, WeChat, Xiaohongshu, ecommerce, and A-share research workflows.
- Add example tasks and expected output samples.

## Phase 2: CLI and Converters

- Support `list`, `lint`, `build`, `install`, and `pack`.
- Generate Claude Code, Codex, Cursor, OpenCode, VSCode Copilot, Trae, and generic AGENTS.md outputs.
- Add platform capability warnings when an agent uses unsupported tools.

## Phase 3: Website

- Browse, search, and filter agents.
- Build recommended stacks for founders, engineers, marketers, data analysts, and content teams.
- Generate copy-paste install commands.

## Phase 4: Community

- Add contribution templates and PR checks.
- Add agent quality scoring.
- Add duplicate-scope detection.
- Add curated collections and contributor credits.
