# Collections

Collections are installable packs of agents for a complete workflow.

## Current Packs

- `solo-founder-pack`: product, UX, frontend, API, landing copy, SEO, and social planning.
- `code-quality-pack`: code review, debugging, testing, security, prompt-injection review, and repo onboarding.
- `china-growth-pack`: Xiaohongshu, WeChat, Feishu, cross-border ecommerce, market research, and landing copy.
- `agent-maker-pack`: agent evaluation, safety review, product framing, review, and automation design.
- `data-ops-pack`: data analysis, spreadsheets, backtests, automation, and repo onboarding.

## CLI

```bash
node packages/cli/bin/lazy-agent-shelf.js collections
node packages/cli/bin/lazy-agent-shelf.js install-collection solo-founder-pack --target codex --out generated/install
```
