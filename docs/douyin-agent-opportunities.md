# 抖音生态高价值 Agent 机会清单

这个清单用于扩展 Lazy Agent Shelf 的中国增长类 agent。优先选择能把“内容、投流、交易、私域、数据”连接起来的高价值场景，而不是只做泛泛的选题或文案。

| 优先级 | Agent 方向 | 适用用户 | 核心价值 | 主要输入 | 主要输出 |
| --- | --- | --- | --- | --- | --- |
| P0 | 抖音投流优化专家 | 本地生活、电商、线索、直播间运营 | 找到烧钱瓶颈，形成素材-计划-预算-转化闭环 | 投流目标、账户数据、素材、预算、转化链路 | 诊断、素材 brief、出价预算动作、测试计划 |
| P0 | 直播间增长操盘 Agent | 直播电商、本地团购、知识付费 | 把投流、主播话术、货盘、节奏和场控联动优化 | 直播复盘、在线人数、停留、成交、货盘 | 直播复盘、排品节奏、话术优化、场控 SOP |
| P0 | 短视频爆款拆解 Agent | 品牌、自媒体、商家、MCN | 批量拆解高互动视频，提炼可复用结构 | 对标账号/视频链接、行业、产品卖点 | 爆款结构、脚本模板、镜头表、选题库 |
| P0 | 本地生活团购运营 Agent | 餐饮、丽人、亲子、休闲娱乐 | 连接达人探店、团购套餐、POI、投流和到店转化 | 门店信息、套餐、达人内容、核销数据 | 套餐优化、达人 brief、POI 内容计划、核销复盘 |
| P1 | 抖店商品卡/搜索优化 Agent | 抖店商家、货架电商团队 | 提升商品标题、主图、卖点、搜索与推荐承接 | 商品信息、竞品、评价、成交关键词 | 商品页诊断、标题主图方案、卖点矩阵 |
| P1 | 达人分销与撮合 Agent | 品牌、团长、精选联盟运营 | 筛选达人、生成邀约话术、评估佣金和带货风险 | 商品、佣金、达人画像、历史带货数据 | 达人名单、邀约私信、佣金建议、风险标记 |
| P1 | 巨量云图人群洞察 Agent | 中大型品牌、代理商 | 把人群资产、兴趣偏好和内容策略连接起来 | 人群包、行业、品牌资产、转化数据 | 人群分层、内容偏好、投放策略、复购建议 |
| P1 | 抖音内容日历 Agent | 品牌号、创始人 IP、本地商家 | 把热点、节点、产品节奏变成可执行发布计划 | 品牌定位、目标、产品节奏、节点 | 月度日历、选题、脚本方向、发布时间建议 |
| P1 | 评论区与私信转化 Agent | 线索业务、本地商家、知识付费 | 把评论和私信沉淀成销售线索和 FAQ | 评论/私信样本、产品 FAQ、转化目标 | 回复话术、线索分级、FAQ、客服 SOP |
| P2 | 抖音合规风控 Agent | 广告主、MCN、品牌内容团队 | 降低素材审核、违规词、夸大承诺和账号风险 | 脚本、商品类目、投放目标、历史违规 | 风险标记、替代表达、审核前 checklist |
| P2 | 竞品监控与行业周报 Agent | 品牌、投放团队、代理商 | 追踪竞品素材、活动、达人和价格变化 | 竞品账号、关键词、商品、达人 | 周报、机会点、素材趋势、价格/活动变化 |
| P2 | 素材生产排期 Agent | 内容团队、代理商、直播间 | 把测试假设拆成拍摄任务和交付排期 | 素材 brief、人员、拍摄条件、截止时间 | 分镜、拍摄清单、排期、验收标准 |

## 推荐落地顺序

1. 抖音投流优化专家：商业价值最高，和现有增长/内容类 agent 互补，已新增为 `douyin-ad-optimizer`。
2. 短剧制作增长专家：已新增为 `short-drama-production-agent`，适合覆盖短剧立项、脚本、投流素材和制作排期。
3. 直播间增长操盘 Agent：适合和投流 agent 组合，能覆盖直播电商和本地生活高预算场景。
4. 短视频爆款拆解 Agent：输入门槛低，适合作为素材生产上游。
5. 本地生活团购运营 Agent：适合中国本地化差异，和通用海外增长 agent 区分明显。
6. 达人分销与撮合 Agent：适合进一步连接达人、佣金和商品转化。

## 组合工作流

- 爆款拆解 -> 素材生产排期 -> 投流优化 -> 评论私信转化。
- 本地生活套餐 -> 达人探店 brief -> POI 内容日历 -> 投流复盘 -> 核销复盘。
- 抖店商品页优化 -> 达人分销 -> 千川投放 -> 直播间复盘。

## 暂不建议优先做的方向

- 纯热点追踪 Agent：容易同质化，缺少交易闭环。
- 只生成标题/脚本的 Agent：现有内容 agent 已能覆盖一部分，除非绑定平台数据复盘。
- 声称破解推荐算法的 Agent：不可验证，风险高，容易误导用户。
