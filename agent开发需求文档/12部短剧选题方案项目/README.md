# 12 部短剧选题方案项目

本目录沉淀的是面向编剧团队评审的**短剧选题清单**：6 大题材 × 每题材 2 部 = 12 部完整选题。每部选题给出正式剧名、爆款引流长剧名、核心立意和核心主题四个字段，作为后续立项、扩写、分集开发的起点。

> 本目录是编剧团队内部评审材料，用于在大量待选题材中先收敛 12 部候选，再决定哪几部进入剧本扩写阶段。不是成片剧本、不是分镜，也不是对外宣发素材。

## 每部选题的标准字段

无论题材，每部选题都对齐以下四项（HTML / PDF 内每张卡片结构一致）：

| 字段 | 作用 |
| --- | --- |
| **正式原版剧名** | 上线挂角标使用的正名（《留洋风云》《股神重生》等） |
| **爆款引流长剧名** | 投流/分发使用的长标题，必须包含明确爽点（重生 / 王者归来 / 万亿资产 / 跪求复合 等） |
| **核心立意** | 一段话讲清主角处境 → 转折 → 反杀逻辑 |
| **核心主题** | 一句话浓缩"什么人 + 什么打法 + 什么结果" |

## 12 部共同的内容模型

读完所有 12 部能看到非常一致的爽剧公式（这是评审时的关键判断依据，也是后续扩写时的安全模板）：

> **失意主角**（破产 / 被甩 / 被踢断腿 / 被流放 / 被开除 / 穷小子）→ **外挂触发**（重生 / 穿越 / 隐藏身份 / 神秘资助 / 先知记忆）→ **逐步崛起**（学校 / 股市 / 商场 / 球场 / 海外 / 乱世）→ **回头打脸**（前女友跪求 / 仇人入狱 / 看不起他的人巴结）。

四个爽点钩子高频出现：
- **重生 / 穿越**（占 8 部）
- **王者归来 / 隐藏身份**（占 4 部）
- **打脸羞辱过自己的人**（几乎所有）
- **量级跨越**（千亿 / 万亿 / 国家队 / 财阀 / 首富）

## 使用建议

### 给编剧团队（评审场景）
直接开 `index.html`，按题材锚点跳转 + 关键词搜索；评审打分后从 12 部中收敛到 3–5 部进入剧本扩写。

### 给制片 / 投流
对照 V2 PDF 的"爆款引流长剧名"字段，可以直接作为投流素材标题或封面文案的起点。

### 给后续扩写
每部选题的"核心立意"是一段话压缩，扩写时需要补：
1. **主角具体设定**（年龄、职业、家庭关系、缺陷）；
2. **第 1 集开局钩子**（多少秒内必须出现第一个反转）；
3. **每 10 集一个阶段目标**；
4. **量级跨越的台阶**（百万 → 千万 → 亿 → 百亿 → 千亿，每一级要有对应事件）；
5. **打脸节点表**（每个反派/前任/旧上司分别在第几集被打回原形）。

## 下一步建议

1. **评审打分**：让编剧团队按"爽点强度 / 投流潜力 / 制作成本 / 合规风险"四个维度对 12 部打分，选 Top 3–5 进入扩写。
2. **合规预筛**：股市 / 金融 / 战争 / 乱世 / 出海类题材有特定合规风险（金融"保证收益"、战争年代政治正确、出海涉及国别敏感），扩写前先过法务红线清单。
3. **标题 A/B 池**：把"爆款引流长剧名"作为投流测试的种子文案，可以在每部选题下扩出 3–5 个变体先做小流量测试，再决定哪部值得重资源投入。
4. **统一开发卡模板**：进入扩写阶段后，每部选题应有同构的开发卡（主角、配角、阶段目标、打脸节点、量级台阶），便于横向比较和资源调度。
