/ 01

v1 已经定下来的边界

四份分析的共识，v2 照单全收，不再讨论。

  1. 不碰金融化：真钱合约、杠杆、可提现预测市场、皮肤竞猜、饰品下注，全部不做。
  2. 不做"游戏杂货铺"：先深耕 CS2，相似品类只筛选可转移、可反复交易、可自动交付的资产。账号 / 金币 / 代练 / 代充 / 绑定装备不做。
  3. 不打补贴战：补贴换来的留存不形成壁垒。
  4. Polymarket 只能当数据因子：不能做下注入口、不能给受限地区导流。
/ 02

v1 没说透的 5 个补充判断

这 5 条是 v2 的增量，也是方向重排的依据。

补充 01 · 真风险

最大单点风险是 Valve，不是合规、不是 BUFF

v1 只用一句话提到 "Steam Market 在补 float/pattern 筛选可能吃掉标准化交易"。这其实是平台估值的天花板。

Valve 历史上有过收紧 Trade Hold 的先例；Steam Market 自带 5% 抽成 + 信用背书，标准化交易这块第三方永远赢不了。

v2 第一过滤器：任何方向如果 Valve 自己也可能做，就不押重注。安全区是 Valve 不愿意做的事——人民币入金、租赁、高端鉴定、大额 P2P 担保、中文社区。

补充 02 · 真对手

真正的对手是 BUFF，不是 Polymarket

v1 花大量篇幅讨论 Polymarket 合规，但日常竞争对手是 BUFF。BUFF 已有：行情指数、库存估值、租赁、社区。

BUFF 弱点：移动端体验、租赁履约链路、客服响应、高端鉴定专业度。

悠悠优势：移动端起家、租赁链路深、客服口碑。方向必须挑 BUFF 做不好的、不是它已经在做的。

补充 03 · 单元经济学

租赁的单元经济学没人讨论

增长分析给租赁 92 分（最高），但押金风险、损坏率、违约率、客服成本这些决定生死的数字一行都没有。

高端饰品出租 → 一旦走失/被换账号，单笔损失数千到数万。租赁本质是金融化租赁业务，参考体系是 Klook 设备租赁 + 共享充电宝押金风控，不是 SaaS。

结论：押注租赁，配套必须先上风控 Agent + 强 KYC + 黑名单。先建风控、再放量。

补充 04 · AI 是产品

AI / 大模型本身可以是产品，不只是后台

v1 把 Agent 都当后台工具。但 LLM 多模态在 CS2 上有非对称机会：

· AI 估价 + 鉴定助手：上传截图自动识别 float / pattern / 印花组合，秒出估值。
· AI 投资助理：基于库存做盈亏归因、调仓建议、风险提示。
· AI 搭配师：基于预算 / 英雄 / 职业哥同款生成可买/可租套装。

国内尚无对手做出像样产品，是 v1 完全漏掉的机会。

补充 05 · 海外窗口

海外窗口被低估

国内合规上限是死的。但海外（CSFloat / Skinport / DMarket）格局未定。中文团队做海外 CS2 工具型 SaaS（不碰托管资金、不做撮合）反而可能跑出来——卖订阅、卖数据 API、卖鉴定服务。不碰资金 → 合规风险大幅下降，现金流量级小但毛利高，是优质第二曲线。
