# 硬核系列短剧规划

本目录沉淀的是「硬核系列」知识爽剧 IP 的内部规划材料，回答三个问题：

1. 什么是「硬核系列」，为什么现在做；
2. 首发母体作品《硬核穿越者》四部 240 集怎么落地；
3. 在 AI 短剧规模化生产时，知识表达的边界在哪、哪些内容不能上线。

> 本目录是公司内部规划文件，用于统一方向、组织资源、指导前期内容开发，不对外融资、不作为对外宣发素材。涉及高风险知识（火药、武器、危险化学、家庭可复现实验等）必须按"分级实操"口径处理。

## 核心判断

### 1. 不再做"普通 AI 短剧"，做"知识爽剧"

AI 视频、数字人、自动配音、批量剪辑和多平台分发能力已经成熟，普通爽剧拼情绪、拼题材，同质化严重、IP 沉淀弱。

「硬核系列」的位置是：

> 用短剧的高密度冲突和连续追更机制，把知识点包装成具体破局场景。

观众不是来上课，而是来"看主角用脑子赢"。看完每集至少记住一个**可迁移的判断**，而不是一段课文。

### 2. 内容公式（系列统一）

**爽文题材 + 真实知识 + AI 短剧生产 + 连续剧追更**

每集必须能回答四个问题：

1. 主角为什么必须用知识？
2. 这个知识点如何产生爽感？
3. 观众看完能记住什么？
4. 这个知识点能否延伸成下一集钩子？

### 3. 首发以《硬核穿越者》验证模型

| 部次 | 集数 | 名称 | 主成长线 | 核心知识资产 |
| --- | --- | --- | --- | --- |
| 第一部 | 1–60 | 生存与立业 | 破庙秀才 → 县城新贵 | 卫生、照明、造纸、印刷、账本、商品化 |
| 第二部 | 61–120 | 信息与工程 | 县城商人 → 朝廷技术顾问 | 香料、指南、地图、测量、后勤、边防工程 |
| 第三部 | 121–180 | 工业基础 | 作坊主 → 区域工业组织者 | 能源、材料、标准件、机械、道路、水利 |
| 第四部 | 181–240 | 天下新局 | 技术组织者 → 新秩序设计者 | 通信、教育、公共卫生、金融、治理、技术伦理 |

跑通后再复制到《硬核厨神》《硬核英语》《硬核程序员》等衍生系列。

### 4. 单集创作公式（60 秒为主，最长 90 秒）

| 时段 | 功能 |
| --- | --- |
| 0–10 s | 承接上集钩子，抛出本集危机 |
| 10–45 s | 主角用知识拆解，展示关键动作或判断 |
| 45–55 s | 结果反转，关系或局势变化 |
| 55–60 s | 下集钩子 |

成片比例：场景知识 / 操作画面 / 对比结果 / 主角判断 ≈ 70%；人物冲突 / 爽点反馈 / 关系推进 / 下集钩子 ≈ 30%。

### 5. 三线并行原则

> 知识负责破局，情感负责留人，关系负责追更。

- **知识线**：每集一个具体知识点；
- **情感线**：让用户关心人物命运（王娘子、张铁匠、沈账房等关键配角）；
- **权力线**：放大冲突、推动长期追更（商帮嫉妒、官府试探、旧贵族压制）。

## 风险分级（强制执行）

这是整个系列必须遵守的对外口径，**所有剧本立项前先打等级**。

| 等级 | 类型 | 对外处理方式 | 示例 |
| --- | --- | --- | --- |
| L1 | 低风险生活知识 | 可步骤化呈现，保证准确和安全 | 净水、食物保存、记账、印刷排版、基础测量 |
| L2 | 中风险工艺知识 | 讲原理与场景，不展示关键比例/参数/完整流程 | 制皂、酿造、玻璃、水泥、冶炼、蒸汽原理 |
| L3 | 高风险敏感知识 | 只做历史背景、概念解释、剧情结果，不展示可复现方法 | 火药、枪械、武器结构、危险化学反应 |
| L4 | 禁止操作内容 | 不进入剧本，不通过隐晦表达替代 | 自制爆炸物、武器制造、规避监管、伤害性操作 |

中高风险镜头优先使用：图纸关键部分遮挡 / 远景操作 / 安全替代物（模型、水、沙、木块）演示原理 / 只拍失败后果与安全警示 / 把重点放在账本、组织、调度、质检、训练和边界选择。

## 怎么用这套文档

### 给制片 / 总导演

- 先读 `docs/ip-plan.md` 第二、三、五章（总定位、首发选择、单集公式）；
- 再读 `docs/traveler-plan.md` 第二、三章（核心原则、角色设定）；
- 制作前过一遍第十章「统一生产指引」与样片建议。

### 给编剧 / 分集开发

- 直接对照 `docs/traveler-plan.md` 第六章「第一部 60 集分集规划」；
- 每集开写前必须填写第 10.1 节「每集开发卡」十字段；
- 标题方向遵循第 10.2 节，禁止"教学型"标题。

### 给审核 / 合规

- 重点看 `ip-plan.md` 第 4.2 节（风险分级原则）；
- 对照 `traveler-plan.md` 第 2.2 / 2.4 节（分级实操口径、中高风险表达边界）；
- 任何 L3 / L4 内容必须二次复核。

### 给 AI 短剧生产 / Agent 开发

- 看板字段、单集结构、镜头要求、字幕规则在 `ip-plan.md` 第五章；
- 「每集开发卡」十字段（`traveler-plan.md` 第 10.1）适合作为 Agent 的结构化输入；
- 知识等级 L1–L4 适合作为内容审核 Agent 的红线规则。
