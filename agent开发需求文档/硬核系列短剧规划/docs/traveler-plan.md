## 一、项目定位

《硬核穿越者》是《硬核系列》知识爽剧IP的首发母体作品。

本剧核心定位：

> 爽剧为壳，知识为核；用短剧节奏承载场景知识，用人物关系拉动长期追更。

主角林默穿越到北宋仁宗景祐三年，从破庙求生开始，依靠现代基础知识、工程化思维、商业流程和组织能力，一步步建立作坊、打开市场、进入权力场，最终推动一个时代的生产方式、教育方式和治理方式发生变化。

本剧不是课堂，也不是单纯开挂爽文。观众要看到的是：

1. 主角每次遇到具体危机。
2. 危机背后有一个可理解的知识点。
3. 知识必须在剧情里产生真实后果。
4. 每次破局都改变人物关系、利益格局和主角身份。

统一主张：

> 万一观众真的穿越了，看完至少知道第一步该从哪里下手。

## 二、核心内容原则

### 2.1 场景知识破局

每集只讲一个核心知识点，知识必须从剧情冲突中自然长出来。

不能为了讲知识而停下剧情，也不能为了狗血剧情牺牲知识逻辑。最好的结构是：

> 人物遇到麻烦 -> 主角看出本质 -> 用知识做低成本试验 -> 出现结果 -> 关系和局势发生变化。

### 2.2 分级实操

本剧采用“分级实操”口径：

> 能安全学的，就具体教；可能出事的，就讲边界；明显危险的，只服务剧情。

| 等级 | 内容类型 | 成片表达 |
|---|---|---|
| L1 低风险 | 饮水、卫生、账本、包装、抄纸、排版、测量、地图、经营流程 | 具体呈现材料、工具、动作顺序、成败判断和常见错误 |
| L2 中风险 | 制皂、酿造、香膏、花露、食品加工、冶炼、水泥、蒸汽、燃料 | 呈现安全版实操、关键观察点、专业场景和安全边界，不给危险参数 |
| L3 高风险 | 火药、枪械、炸药、武器结构、危险化学、战术杀伤 | 只讲历史、结果、组织、伦理、后勤和剧情后果，不做操作 |
| L4 禁止 | 可直接造成伤害或规避监管的做法 | 不进入剧本，不通过隐晦表达替代 |

### 2.3 低风险知识必须具体

日常生活、经营和安全手工是《硬核穿越者》的知识爽感基础。凡是L1内容，尽量拍出五件事：

1. **材料**：镜头扫过3-5个关键物件。
2. **工具**：手部拿起工具，说明用途。
3. **步骤**：每步一个短镜头，字幕使用动词开头。
4. **判断**：给出颜色、形态、软硬、厚薄、气味、声音或账面结果。
5. **常见坑**：用学徒、反派或顾客问出错误做法，主角立刻纠正。

可具体拍的内容包括：

- 饮水沉淀、过滤、煮沸。
- 晒衣、烫洗、虫患隔离。
- 灯芯调整、容器防风、照明对比。
- 账本、赊账、押金、签押、分红。
- 纸浆搅拌、抄纸动作、晾晒编号。
- 活字排版、校对流程、雕版适用场景。
- 包装、防伪、分级定价。
- 防潮、防火、库存分区。
- 罗盘指向、地图比例、路线记录。
- 花露、香膏、香料包装等安全香氛内容。

### 2.4 中高风险内容表达边界

以下内容不写成可复现教程：

- 火药、炸药、枪械、武器结构。
- 危险化学反应。
- 高压锅炉、压力容器、危险机械制作。
- 易燃燃料的分离、储存和攻击用途。
- 可直接模仿并造成伤害的实验。

中高风险内容优先使用以下镜头：

- 主角看图纸，但关键细节被遮挡。
- 工匠远景操作，不展示步骤。
- 用模型、水、沙、木块等安全替代物演示抽象原理。
- 只拍失败后果、安全警示和责任制度。
- 把重点放在账本、组织、调度、质检、训练和边界选择。

## 三、世界观与主角设定

### 3.1 基础世界观

主角林默，现代普通理工男，熟悉基础工程、产品流程和常见民用技术。穿越到北宋仁宗景祐三年，附身在一个父母双亡、家徒四壁的破落秀才身上。

他没有系统，没有无限物资，也没有无敌武力。随身只有一本被水泡残的《民用工业手册》。这本手册不提供完整答案，只留下目录、草图和原则，很多细节必须靠林默自己试错、找材料、请工匠、建流程。

主角不是“背答案的人”，而是“知道方向、能组织验证的人”。

### 3.2 主角核心能力

| 能力 | 剧情表现 |
|---|---|
| 基础科学判断 | 看出湿气、污染、成本、效率、误差等问题本质 |
| 工程化思维 | 把一次成功变成多人可复制流程 |
| 商业化能力 | 明白产品、定价、复购、账期、渠道和品牌 |
| 组织能力 | 招人、培训、质检、分工、保密和激励 |
| 风险意识 | 知道哪些技术不能随便扩散，主动设边界 |

### 3.3 关键配角

| 角色 | 剧情功能 | 情感功能 |
|---|---|---|
| 王娘子 | 第一批合伙人，负责门店、女客市场、口碑传播 | 与林默形成暧昧、信任、并肩成长线 |
| 张铁匠 | 工具、模具、机械和工坊升级的关键人物 | 从不服到佩服，形成硬核友情线 |
| 沈账房 | 账本、成本、分红、供应链和商业执行 | 理性搭档，负责把理想拉回现实 |
| 小石头 | 学徒视角，承担观众替身 | 负责问出最简单、最真实的问题 |
| 周纸商 | 第一阶段商业反派，代表旧行会和垄断利益 | 因嫉妒和恐惧不断升级冲突 |
| 县令 | 官府接口，既需要主角能力，也警惕他坐大 | 权力试探线，推动主角进入官商关系 |
| 海商许衡 | 引出指南、地图、海贸、香料和外部世界 | 打开第二部的远方线 |
| 老工匠群体 | 代表经验主义，也负责让现代知识落地 | 与主角共同完成“经验+原理”的融合 |

### 3.4 情感与群像原则

本剧必须有知识线、情感线和权力线三条线并行。

| 线索 | 作用 | 示例 |
|---|---|---|
| 知识线 | 每集一个具体知识点 | 林默用抄纸、账本、香膏、罗盘解决问题 |
| 情感线 | 让用户关心人物命运 | 王娘子从怀疑到信任，张铁匠从不服到并肩 |
| 权力线 | 放大冲突和长期追更 | 商帮嫉妒，官府试探，旧贵族压制，新势力结盟 |

创作要求：

1. 不写与知识无关的狗血剧情。
2. 每个知识破局背后，都要有人受益、有人嫉妒、有人失去利益、有人重新选择站队。
3. 爱情和友情不能只是点缀，要推动角色选择。
4. 反派不能只是坏，要代表旧经验、旧利益、旧秩序或恐惧心理。
5. 主角的胜利不能只有“做成了东西”，还要带来关系变化、身份变化和权力格局变化。

统一创作原则：

> 知识负责破局，情感负责留人，关系负责追更。

## 四、四部曲总规划

### 4.1 四部240集总览

| 部次 | 集数 | 名称 | 主成长线 | 核心知识资产 | 结尾悬念 |
|---|---:|---|---|---|---|
| 第一部 | 1-60 | 生存与立业 | 破庙秀才到县城新贵 | 卫生、照明、造纸、印刷、账本、商品化 | 东京贵人和海商同时找上门 |
| 第二部 | 61-120 | 信息与工程 | 县城商人到朝廷技术顾问 | 香料、指南、地图、印刷、测量、后勤、边防工程 | 主角被调入更大的权力场 |
| 第三部 | 121-180 | 工业基础 | 作坊主到区域工业组织者 | 能源、材料、标准件、机械、道路、水利 | 皇权、商帮和旧贵族开始联手压制 |
| 第四部 | 181-240 | 天下新局 | 技术组织者到新秩序设计者 | 通信、教育、公共卫生、金融、交通、治理、技术伦理 | 开启新朝代、新世界线或衍生篇 |

### 4.2 每部内部节奏

每部60集采用统一节奏：

- **每3集一个小冲突**：一个局部问题，一个小反转，一个知识记忆点。
- **每10集一个大节点**：一个阶段目标完成，主角身份或资源升级。
- **每30集一个中段高潮**：旧敌人升级，主角从产品升级到体系。
- **每60集一个终极悬念**：引出下一部更大的世界。

### 4.3 单集结构

单集建议控制在60秒，复杂集可延长至90秒。

| 时长 | 内容 |
|---|---|
| 0-10秒 | 承接上集钩子，抛出本集危机 |
| 10-45秒 | 主角用知识拆解问题，展示关键动作或关键判断 |
| 45-55秒 | 结果反转，人物关系或局势发生变化 |
| 55-60秒 | 下集钩子 |

成片比例：

- 70%：场景知识、操作画面、对比结果、主角判断。
- 30%：人物冲突、爽点反馈、关系推进、下集钩子。

## 五、第一部《生存与立业》

### 5.1 第一部定位

**集数**：第1-60集  
**时间**：穿越后0-3个月  
**核心主题**：从破庙求生到县城新贵  
**核心爽点**：别人靠祖传经验，林默靠基础原理和标准流程  
**核心成果**：活下来，赚到钱，建立第一家作坊，形成“硬核工坊”品牌雏形  

第一部最重要的是立住观众认知：

> 林默不是神仙，他只是比古人更懂卫生、效率、成本、标准和复购。

### 5.2 第一部六个十集阶段

| 集数 | 阶段名 | 阶段目标 | 主冲突 | 知识方向 |
|---|---|---|---|---|
| 1-10 | 破庙求生 | 活下来，恢复体面 | 饥寒、病污、身份低微 | 水、卫生、清洁、盐、照明 |
| 11-20 | 第一件商品 | 用低成本产品换钱 | 市集不信任、同行嘲笑 | 蜡烛、灯芯、包装、定价 |
| 21-30 | 纸坊起势 | 找到更高壁垒的生意 | 恶霸和旧商户打压 | 造纸、原料、打浆、抄纸、质检 |
| 31-40 | 印书破局 | 从卖纸升级到卖信息 | 纸商降价、书生需求 | 活字、雕版、排版、校对 |
| 41-50 | 商品矩阵 | 建立高毛利产品线 | 大商人压价、原料短缺 | 糖、香料、账本、供应链 |
| 51-60 | 作坊成型 | 建立组织和品牌 | 官府试探、商帮围剿 | 标准化、分工、质检、信用 |

### 5.3 第一部核心关系推进

| 阶段 | 关系变化 |
|---|---|
| 1-10集 | 林默从“疯秀才”变成“还有点本事的人” |
| 11-20集 | 王娘子加入，主角第一次有员工和门店 |
| 21-30集 | 张铁匠加入，工具和工艺开始升级 |
| 31-40集 | 沈账房加入，作坊从手艺变成生意 |
| 41-50集 | 海商许衡登场，外部世界打开 |
| 51-60集 | 县令正式介入，主角进入官商关系网 |

以下为分集开发表。每集只保留“剧情功能”和“知识记忆点”，用于后续扩写1分钟分镜头脚本。

### 7.3 香膏、花露与水蒸气提香

香膏、花露是第二部重要的“低中风险实操样板”，要让观众看懂水蒸气提香和油脂吸香的基本思路。

可拍内容：

- **水蒸气提香**：锅中放清水和鲜花，上方用干净容器或冷凝斜面收集带香气的冷凝水。
- **原理表达**：水蒸气带走挥发性香气，遇冷变回水，形成带香气的花露。
- **冷凝判断**：盖子或冷凝面要保持冷，看到水珠聚集并滴下，说明香气被带出。
- **花材选择**：花要新鲜、无腐烂，越快处理香气越完整。
- **香膏制作**：用油脂反复吸收花香，再用蜂蜡帮助定型，装入小盒密封。
- **商业包装**：小盒、防漏、标签、香型命名、试用装、女客口碑。

边界：

- 不展示高浓度酒精蒸馏。
- 不展示密闭加压装置。
- 不暗示家庭或普通作坊可以随意处理易燃溶剂。
- 不写危险比例和危险替代材料。

### 7.4 第二部结尾

边境危机中，林默靠地图、信号、道路、仓储和训练，让一支原本混乱的队伍完成快速调度。皇帝第一次意识到：

> 这个人危险的不是会做某件器物，而是会重建一整套系统。

结尾悬念：林默被调入京城，进入更大的权力场。

## 十、统一生产指引

### 10.1 每集开发卡

每集开写前必须填写：

| 字段 | 内容 |
|---|---|
| 集数 | 第几集 |
| 阶段 | 属于哪个10集阶段 |
| 本集危机 | 主角遇到什么具体麻烦 |
| 知识点 | 本集只讲一个什么知识 |
| 等级 | L1/L2/L3/L4 |
| 画面重点 | 手部、道具、对比、账本、图纸或结果 |
| 爽点 | 谁被打脸，局面如何反转 |
| 情感推进 | 哪段关系发生变化 |
| 权力变化 | 谁受益，谁受损，谁开始警惕主角 |
| 钩子 | 下一集为什么非看不可 |

### 10.2 标题风格

标题要有短剧冲突，但不能制造危险教程感。

推荐方向：

- “全城都笑他卖破纸，三天后书生堵满门口”
- “纸商降价逼死他，他反手卖出三种纸”
- “县令想查封作坊，一本账让他改了主意”
- “海商问他怎么不迷路，他画出一张没人见过的图”

禁止方向：

- “教你制作某某危险物”
- “某某配方公开”
- “一招做出武器”
- “普通人也能复刻某危险技术”

### 10.3 样片建议

第一阶段建议先做3支样片：

| 样片 | 用途 |
|---|---|
| 第1集：破庙醒来 | 测试穿越开局、人物质感、旁白节奏 |
| 第10集：第一支蜡 | 测试手部特写、知识可视化、结果爽点 |
| 第40集：一天卖空三百本 | 测试商业高潮、群像反应、IP调性 |

这三支样片分别代表“生存”“技术”“商业爽点”，能快速判断《硬核穿越者》的整体成立度。

## 十一、结论

《硬核穿越者》是《硬核系列》的第一部母体IP，承担三项任务：

1. 立住“知识爽剧”的观看体验。
2. 建立AI短剧可复制生产模板。
3. 为后续《硬核厨神》《硬核英语》《硬核程序员》等系列提供内容方法。

本剧最终要让观众记住一个判断：

> 知识能破局，流程能放大知识，组织能改变时代。

第一部《生存与立业》负责打底：立住林默，立住群像，立住短剧节奏，立住低风险可实操模板。第二部打开信息、工程和外部世界。第三部进入工业基础。第四部进入治理、教育、通信和天下新局。

四部240集完成后，《硬核穿越者》不只是一部穿越短剧，而是“硬核系列”知识爽剧方法论的第一块样板。
